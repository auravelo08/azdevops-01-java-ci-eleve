# Atelier 01 · API Java et intégration continue — élève

**4 h 30 · Bac+4/5 · Java17, Maven et GitHub Actions.** Construire une API de cotations fictives, la tester, produire un JAR et prouver qu'une PR incorrecte est refusée par la CI. Cet atelier ne nécessite pas Azure et ne dépend d'aucun autre projet.

Ce dépôt contient uniquement le parcours, les mémos et les espaces de réponse. Créez vous-même source, tests, pom et workflow dans votre copie personnelle. Le corrigé est séparé et communiqué après restitution.

## Résultat attendu

Deux routes GET en JSON, erreurs HTTP correctes, huit tests utiles, JAR autonome, CI main/PR, rapports et artefacts, PR rouge puis verte. L'installation des outils et comptes est terminée avant les 270 minutes. Les preuves restent honnêtes si la plateforme est indisponible.
